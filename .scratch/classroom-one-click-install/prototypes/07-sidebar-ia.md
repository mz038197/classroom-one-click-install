## 變體 A — 上下兩段（環境在上、本課在下）

模擬：已裝 uv；尚未裝 git；Node 已就緒。本課有一筆成功、一筆因缺 git 禁用、一筆可點。

```
┌─ 課堂一鍵安裝 ─────────────────┐
│ 工作區：my-course-project       │
│                                 │
│ ▼ 環境工具                      │
│   [重新檢查]                    │
│                                 │
│   uv     ✓ 0.7.x                │
│          [重新安裝／修復]        │
│                                 │
│   git    ✗ 未安裝               │
│          [安裝]                 │
│                                 │
│   Node   ✓ v22.x (npm ok)       │
│          [重新安裝／修復]        │
│                                 │
│ ⚠ 建議先安裝 git（部分本課項目   │
│   需要）                        │
│                                 │
│ ▼ 本課安裝                      │
│   來自 classroom-installs.yaml  │
│                                 │
│   ✓ 安裝 peas-agent-tools       │
│     從 GitHub 加入專案依賴       │
│     狀態：成功                   │
│     [再執行…]                   │
│                                 │
│   ○ 安裝 peas-agent-runtime     │
│     （需要 git — 已禁用）        │
│                                 │
│   ▶ 安裝 dataset-streamlit-shell│
│     以 uvx 執行安裝入口          │
│     [安裝]  ← 點了會先確認命令   │
│                                 │
└─────────────────────────────────┘
```

點「安裝」後的確認（示意）：

```
┌─ 確認執行 ──────────────────────┐
│ 安裝 dataset-streamlit-shell    │
│                                 │
│ 將在工作區根目錄執行：           │
│ uvx --from git+https://… \      │
│   add-dataset-streamlit-shell \ │
│   --update                      │
│                                 │
│        [取消]    [執行]         │
└─────────────────────────────────┘
```

環境工具裝完後（示意）：

```
│   git    … 請重開終端機後        │
│          按「重新檢查」          │
```

進行中：

```
│   ▶ 安裝 dataset-streamlit-shell│
│     狀態：進行中…（見終端機）    │
```

失敗：

```
│   ✗ 安裝 peas-agent-runtime     │
│     狀態：失敗 — 檢查 git／網路  │
│     ／repo 是否公開；詳見終端機  │
│     [重試]                      │
```

## 變體 B — 本課優先（本課在上、環境可摺疊）

上課時學生多半先找「要裝的套件」；環境區預設收合，未就緒時在頂部一條警告。

```
┌─ 課堂一鍵安裝 ─────────────────┐
│ ⚠ 環境：缺 git（點此展開）      │
│                                 │
│ ▼ 本課安裝                      │
│   ✓ 安裝 peas-agent-tools  成功 │
│   ○ 安裝 peas-agent-runtime     │
│     （需要 git）                 │
│   ▶ 安裝 dataset-streamlit-shell│
│     [安裝]                      │
│                                 │
│ ▸ 環境工具（已摺疊）            │
│   uv ✓ · git ✗ · Node ✓         │
│   [重新檢查]                    │
└─────────────────────────────────┘
```

展開環境後內容與變體 A 相同（版本、安裝、重開終端提示）。
