## What to build

Environment Lane 改成勾選 + 一顆「安裝」，拿掉每一列的安裝／修復按鈕，也不要把命令面板當單工具安裝的學生主入口。未安裝與安裝失敗預勾；已就緒與「請重開終端」不預勾（就緒可手動勾當修復）。沒勾任何項時安裝鈕禁用、不提示。一次確認，標題「安裝所選環境工具」，列出此次命令或網址。依固定順序串行；失敗即停；只有正在跑的列顯示安裝中；進行中鎖定勾選與按鈕。裝完仍請重開終端再檢查。Windows 無 winget 時同一批可混指令與開頁。

## Acceptance criteria

- [ ] 列上沒有「安裝」或「重新安裝／修復」；只有勾選、區級「安裝」與「重新檢查」
- [ ] 未安裝與失敗預勾；就緒與請重開終端不預勾；就緒可手動勾
- [ ] 空選取時安裝鈕禁用且不另提示
- [ ] 按安裝只出現一個確認框，標題為「安裝所選環境工具」，內文列齊將執行／將開啟（uv 若有 preview 則附上）
- [ ] 取消確認則不安裝，勾選不變
- [ ] 執行順序 uv → git → Node.js → PowerShell 7（僅跑有勾的）
- [ ] 中途失敗則停止；已成功項為請重開終端；失敗項留 IT 提示；未跑到的維持原狀
- [ ] 僅當前列為「安裝中」；進行中無法改勾選或再按安裝
- [ ] 批次結束後解鎖；成功項不得直接標就緒
- [ ] 命令面板不再提供與列按鈕同等的單工具安裝主入口
- [ ] Course Lane 行為不變（不因缺工具而鎖）
