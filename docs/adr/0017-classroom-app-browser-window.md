# Classroom App 用系統瀏覽器當視窗

Classroom App 的學生表面是本機網頁，用系統預設瀏覽器打開，並用工作列圖示把頁面叫回來。關分頁或關瀏覽器不停止代理。停止仍是 app 裡的單獨動作，按下才停代理並拿掉 Codex 與 Claude 的路由覆寫。

不用 Tauri 或 Electron 包一層視窗，也不為 Windows 和 macOS 各寫一套原生畫面。五區是表單和清單，版面必須隨視窗寬度重排。窄視窗時改成直向堆疊，按鈕和清單仍可操作。不做成只適合寬螢幕的固定寬度。另做視窗殼不會讓代理或設定檔變簡單，還會把安裝包變大。日後若要改成 Tauri，網頁可以留著，RWD 仍要保留。
