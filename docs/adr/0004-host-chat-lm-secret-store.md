# Write Classroom API Key into Host chat.lm.secret storage

VS Code Copilot only resolves `${input:chat.lm.secret.*}` against application-scoped rows (`secret://chat.lm.secret.…` in `state.vscdb`), not extension-scoped SecretStorage (`secret://{"extensionId":…}`). After `secrets.store`, we retry-copy that encrypted blob into the Host key (extension host often has no Electron `safeStorage`). Direct `safeStorage.encryptString` is only a fallback. Trade-off: depends on VS Code’s DB shape/flush timing and needs a window reload after write. Secret id suffixes must match VS Code’s hex shape (`hash(uuid).toString(16)`, e.g. `-7a55c1a5`). Cursor is out of scope for auto BYOK (prompt Portal／手動 instead).
