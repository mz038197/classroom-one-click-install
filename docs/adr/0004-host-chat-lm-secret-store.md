# Write Classroom API Key into Host chat.lm.secret storage

VS Code Copilot only resolves `${input:chat.lm.secret.*}` against application-scoped rows (`secret://chat.lm.secret.…` in `state.vscdb`), not extension-scoped SecretStorage (`secret://{"extensionId":…}`). After `secrets.store`, we retry-copy that encrypted blob into the Host key (extension host often has no Electron `safeStorage`). Direct `safeStorage.encryptString` is only a fallback. **Reload Window is not enough** — VS Code may flush in-memory secrets and drop DB-only Host rows; students must fully quit and reopen, and we re-apply pending Host writes on activate. The toast offers **重新啟動** (delayed relaunch + `workbench.action.quit`), not Reload Window. Secret id suffixes must match VS Code’s hex shape (`hash(uuid).toString(16)`, e.g. `-7a55c1a5`). Cursor is out of scope for auto BYOK (prompt Portal／手動 instead).
