# Write Classroom API Key into Host chat.lm.secret storage

VS Code Copilot only resolves `${input:chat.lm.secret.*}` against application-scoped rows (`secret://chat.lm.secret.…` in `state.vscdb`), not extension-scoped SecretStorage (`secret://{"extensionId":…}`). After `secrets.store`, we retry-copy that encrypted blob into the Host key (extension host often has no Electron `safeStorage`). Direct `safeStorage.encryptString` is only a fallback. **Reload Window is not enough** — VS Code may flush in-memory secrets and drop DB-only Host rows; students need a **Host Full Restart** (complete quit + auto reopen), and we re-apply pending Host writes on activate. The toast **重新啟動** hard-promises that restart: schedule a delayed relaunch (Windows: PowerShell `Start-Sleep 4` + `Start-Process` on `process.execPath`; macOS/Linux: `sleep 4` + exec), and only then run `workbench.action.quit`. If spawn fails synchronously, do **not** quit — show an error and ask for a manual full restart. Secret id suffixes must match VS Code’s hex shape (`hash(uuid).toString(16)`, e.g. `-7a55c1a5`). Cursor is out of scope for auto BYOK (prompt Portal／手動 instead).
