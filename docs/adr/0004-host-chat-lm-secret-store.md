# Write Classroom API Key into Host chat.lm.secret storage

VS Code Copilot only resolves `${input:chat.lm.secret.*}` against application-scoped rows (`secret://chat.lm.secret.…` in `state.vscdb`), not extension-scoped SecretStorage (`secret://{"extensionId":…}`). We encrypt with Electron `safeStorage` and write the Host row directly (do not copy from extension SecretStorage — `secrets.store` may not have flushed to `state.vscdb` yet). Trade-off: depends on VS Code’s DB shape and needs a window reload after write. Secret id suffixes must match VS Code’s hex shape (`hash(uuid).toString(16)`, e.g. `-7a55c1a5`); non-hex ids are not resolved even if the row exists. Cursor is out of scope for auto BYOK (prompt Portal／手動 instead).
